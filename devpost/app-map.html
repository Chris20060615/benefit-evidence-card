Follow one question to its evidence.

This local prototype finds original passages in one public NHSA guide, using a small set of procedural rules. It keeps conditional evidence and unsupported claims visibly distinct. This is a reference route; no participant tour or learning outcome is claimed.

Source preparation happens at server startup: SourceStore.initialize in server.py fetches the fixed official URL or verifies the ignored local cache. parse_document in evidence.py extracts the actual article paragraphs. A question is sent only to the local server.

A three-stop route

  1. web/app.js, submitQuestion: reads the form, sends the question to /api/search and prevents overlapping input. Example buttons use this same function.
  2. evidence.py, search_document: checks unsupported claims and source capabilities before returning exact parsed evidence. An unknown facet must abstain. Read tests/test_evidence.py alongside the function to see bounded development checks.
  3. web/app.js, renderResult: displays the checked question, explicit status, original quotation, section and source link. Text nodes keep question/source content from becoming executable HTML.

To change this, start here

  • Layout and mobile spacing: web/styles.css.
  • Visible form labels and examples: web/index.html. Examples do not bypass retrieval.
  • Supported procedural facets: evidence.py; update meaningful boundary tests with any retained change.
  • Source identity or cache behavior: SourceStore in server.py and SourceCacheTests in tests/test_server.py.

A practice to reuse

The early lexical experiment found that relevant text could still fail to support a claim. The implementation therefore checks answerability separately from topic matching. Independent review then exposed an action mismatch: a viewing instruction cannot answer how to delete a record. Use an observable boundary case to challenge what a feature claims to know; passing a familiar example alone is weaker evidence. See sources/retrieval-feasibility.json, devpost/prd.md and the evidence tests. These are development observations, not a general accuracy score.

Run again

From the project directory, run python -X utf8 server.py --port 8768, then open http://127.0.0.1:8768/. First use needs the official source online. A verified local cache can be used with --offline. See README.md for exact instructions.
